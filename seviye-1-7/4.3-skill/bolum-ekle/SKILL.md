name: bolum-ekle
description: sitene yeni bir bölüm ya da içerik eklerken kullan.
---
Eklenecek bölüm: $ARGUMENTS

1. main güncel mi bak, değilse git pull --ff-only.
2. icerik/<kisa-ad> adında yeni branch aç.
3. Bölümü mevcut sayfanın tasarımına ve marka kurallarına uygun ekle.
   Bilgi uydurma; emin olmadığın yeri bana sor.
4. Telefon, kişisel e-posta ekleme; noindex'e dokunma.
5. Commit et, branch'i push et, PR aç.
6. PR adresini ve önizleme adresini ver.
7. Birleştirme; incelemeyi ve birleştirmeyi ben yaparım.
